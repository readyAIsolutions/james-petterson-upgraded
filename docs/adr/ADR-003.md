# ADR-003 — OpenRouter gateway abstraction with a deterministic offline fallback

**Date:** recorded at alpha architecture decision
**Status:** Accepted

## Context

Several services need LLM calls: NPC dialogue (`npc_dialogue`), case premise drafting (`case_premise`), and potentially narration. The blueprint's rule was "swap models without rewriting the game." Two hard constraints: (1) I must never hard-code model/provider calls into gameplay logic, and (2) the whole vertical slice must be **testable and playable offline** with no paid account.

## Decision

I built a single **AI Gateway** — `src/services/ai-gateway.js` (`AIGateway`) — through which every service that needs an LLM talks. It:

- Routes to providers over OpenRouter's `chat/completions` endpoint (`https://openrouter.ai/api/v1/chat/completions`), defaulting to `openai/gpt-4o-mini` (env-overridable via `DEFAULT_MODEL`).
- Handles **retries with backoff** (4 attempts, 45s abort timeout, longer backoff on 429/5xx), **caching** (in-memory prompt→result), **token/cost budgeting**, and structured JSON mode (`response_format: { type: 'json_object' }`).
- Persists **telemetry** to the `ai_calls` table (purpose, provider, model, tokens, latency, cost, trace id) — note this telemetry must never break gameplay (errors are swallowed).
- Supports **scripted handlers** registered by purpose (`registerScripted(purpose, fn)`).

**Offline fallback:** if `OPENROUTER_API_KEY` is not set, `complete()` calls a registered deterministic scripted handler for the purpose. If no handler exists for an unexpected purpose, it throws with an explicit message. This keeps the price of entry at zero and makes the platform fully deterministic without a network.

The two consumers today wire it naturally:
- `NpcOrchestrator` calls `purpose: 'npc_dialogue'` and registers its deterministic dialogue handler.
- `CaseGenerator` calls `purpose: 'case_premise'` and falls back to a `_templatePremise()` deterministic set.

## Consequences

**Positive**
- Model/provider is swappable by config, not code changes.
- The platform runs and passes tests with no API key (offline mode), which is how CI and the 25-test suite run.
- Cost/latency/trace visibility is built in from day one.

**Negative / tradeoff**
- OpenRouter is a single external dependency for live AI; it is a network hop with variable latency.
- Deterministic fallback quality is intentionally low (template dialogue/premises) — it proves the pipeline, not great prose.

## Path to adjust

Add/swap providers, change budgets, or plug in a local model (e.g. llama.cpp hosted) by replacing the fetch body/endpoint inside the gateway — consumers are untouched. Add a new scripted handler for any new `purpose` to preserve offline determinism.
