# ADR-005 — Deterministic accusation scoring, not LLM-judged

**Date:** recorded at alpha architecture decision
**Status:** Accepted

## Context

When a player submits a final accusation (culprit, motive, method, timeline order), the platform must decide how correct it is. Two options: (a) have an LLM judge the accusation, or (b) score it by comparing against canonical data with a fixed rule set. LLM judging is attractive for "free-form" fairness but is nondeterministic, non-reproducible, gamed-it-can-vary-across-runs, and costs tokens on every accusation.

## Decision

I score accusations **deterministically in the Game Session Service** — `src/services/game-session.js`, `score()` — against canonical manifest data. **No LLM judges the player.** The blueprint's rubric is implemented directly:

| Dimension | Weight | How it's scored |
|-----------|--------|-----------------|
| **Culprit** | 30 | exact match `culpritId === manifest.culprit_id` |
| **Motive** | 15 | normalized keyword overlap between culprit's canonical motive and the given motive (≥0.4 → full, else proportional) |
| **Method** | 15 | normalized overlap with the canonical `fact_method` conclusion (≥0.4 → full, else proportional) |
| **Timeline** | 20 | fraction of canonical critical events the player placed in their order |
| **Evidence** | 15 | fraction of evidence linking to critical facts that the player discovered |

The score's winner/loser breakdown is stored in the `accusations` table (`score`, `breakdown` JSON) and the session is set `status='completed'`. The code comment notes a 5% efficiency dimension reserved for the 95-point ceiling.

**Why deterministic**
- **Reproducible:** the same accusation always yields the same score — essential for tests and fair-play (a player's grade doesn't depend on which prompt the model saw).
- **Transparent:** `breakdown` names each component, so the player and an admin can see exactly where a case was won or lost.
- **Cheap & offline:** zero LLM calls and latency; works in the deterministic offline mode (ADR-003).
- **Honest:** matches Truth-Before-Language (ADR-004) — the grade is a fact about the case data, not a model opinion.

## Consequences

**Positive**
- Scoring is covered by deterministic integration tests and stable across CI runs.
- A correct reconstruction reaches the full (≥) score; the rubric is inspectable by designers.

**Negative / tradeoff**
- Free-form prose motive/method are judged by keyword overlap, which is crude for synonyms/paraphrase compared to an LLM.
- Efficiency (5%) is reserved, not implemented — so the practical ceiling today is 95, not 100.

## Path to adjust

Improve motive/method matching (better normalization, synonym tables, or optional LLM *augmentation* that stays deterministic by mapping to canonical atoms) while keeping the final score derived from canonical data. Do not move the authoritative score to an LLM.
