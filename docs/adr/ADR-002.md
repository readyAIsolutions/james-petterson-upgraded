# ADR-002 — React + Vite + ReactFlow for the frontend

**Date:** recorded at alpha architecture decision
**Status:** Accepted

## Context

The player-investigator needs an interactive investigation surface: a scene to observe, a persistent **evidence board** on which to connect evidence, a **timeline** to reconstruct, interviews, and an accusation/debrief flow. The board in particular is a graph-of-nodes interaction, not a list.

## Decision

I chose a **Vite + React 18 (JSX) SPA with ReactFlow** (`reactflow@^11`) for interactive node/edge rendering.

- Scaffold: `frontend/` Vite app, `@vitejs/plugin-react`.
- `vite.config.js` proxies `/health` and `/api` to the Express backend on `http://localhost:8765`.
- ReactFlow powers the evidence board: `frontend/src/screens/Board.jsx` imports `ReactFlow, { Background, Controls, MiniMap, Handle, Position, useNodesState, useEdgesState }`.
- Screen set in `frontend/src/screens/`: `Landing, Play, Briefing, Scene, Board, Timeline, Suspects, Interview, Accusation, Debrief`, orchestrated by `Play.jsx`.

## Why

- Vite gives fast HMR and a trivial dev server with API proxying.
- React + ReactFlow make the graph-based evidence board a first-class, documented primitive (nodes = evidence/characters, edges = player hypothesis relations) instead of a hand-rolled SVG graph.
- Small, focused dependency surface for a one-player vertical slice.

## Consequences

**Positive**
- The board is genuinely interactive and persists via the `hypothesis_edges` + `sessions.state` backing (ADR-001/004).
- Separation of screens matches the player loop (see GDD §2), so each view maps to one behavior.

**Negative / tradeoff**
- ReactFlow's layout is a graph model, so richer "pinboard" styling needs custom node components.
- SPA state is in `Play.jsx` React state; long-lived cross-tab state relies on the backend session persistence, not the browser.

## Path to adjust

Node/edge types, custom sidebar interactions, and additional canvases (e.g. a map view) are all additive within the existing screen architecture — no new framework.
